## 3. Dot product.

Well... the dot product has two definitions, the algebraic one and the geometrical one. But before that, let's understand what it means.

The dot product answer a simple question... imagine you have two vectors, the dot product will answer to this question:
"How much are these two vectors pointing in the same direction?"

The dot product doesn't measures any direction, length, or any type of rotation. It simply measures the alignment of the vectors.

**Types of dot product:**

1. **Both Vectors point almost on the same direction** - we will get a large and positive dot product
2. **The Vectors are perpendicular** - There is no alignment at all, that why the dot product is zero.
3. **The Vectors have a opposite direction** - They basically fighting each other, that why they are negative

Now we will look at the Algebraic and Geometric way. But before that, I will already throw all the spoilers.
The formulas are different, but the results are the same. It is like measuring somebodies height or looking it up in the passport -> Same height. So that mostly, different  methods, same result.

### 4. Normal vectors

Now, before we think that normal = cute and ordinary.

In mathematics nothing is cute and normal. So normal = perpendicular.

Which is the perpendicular vector?
Imagine you put your phone flat on the table and then place a pencil atop the phone:

```
         ▲   pencil (The normal vector)
         │
         │
    _____┴_____
   /          / (the plane)
  /__________/
```

As we can see, the pencil standing straight up on the screen is the normal vector. 

If you tilt the phone in any direction, the pencil tilts with it. The normal vector tells you the exact direction the surface is facing.

So if we remember:
$$r=p+su+tv$$
We use two direction vectors to generate all the points that lay on the plane.

But thanks to the normal vector we can find the point if the point lies in the plane or above it.

How? by using some simple formulas:
$$(\mathbf{Q} - \mathbf{p}) \cdot n = 0$$
What do they mean? 
- **$P = (p_1, p_2, p_3)$**: A fixed **anchor point** known to be on the plan (The starter point most of the times.)
- $Q = (x, y, z)$:  A test point anywhere in 3D space (It is usually given or we want to check if it is on the plane.
- **$n = (a, b, c)$**: That the normal vector, perpendicular ($90^\circ$) to the plane.

Now we will find the displacement vector:
$$Q - P = \begin{bmatrix} x - p_1 \\ y - p_2 \\ z - p_3 \end{bmatrix}$$

Now we will use the dot product:
$$(Q - P) \cdot n = 0$$

$$\begin{bmatrix} x - p_1 \\ y - p_2 \\ z - p_3 \end{bmatrix} \cdot \begin{bmatrix} a \\ b \\ c \end{bmatrix} = 0$$

This is literally:
$$a(x - p_1) + b(y - p_2) + c(z - p_3) = 0$$
or how people show it all the time:
$ax + by + cz + d = 0$ (where $d = -ap_1 - bp_2 - cp_3$).

But now let us try it:

Let's say that our anchor point is: $P = (2, 3, 1)$ and $n$ = $(1, -2, 3)$

Let's see if point $Q_1 = (5, 6, 2)$ is on the plane:
$$Q_1 - P = \begin{bmatrix} 5 - 2 \\ 6 - 3 \\ 2 - 1 \end{bmatrix} = \begin{bmatrix} 3 \\ 3 \\ 1 \end{bmatrix}$$
Now we will use the got product:
$$(Q_1 - P) \cdot n = (3)(1) + (3)(-2) + (1)(3) = 3 - 6 + 3 = \mathbf{0}$$
That means that the point is on the plane!

Now let's try another one: $Q_2 = (4, 1, 1)$

We find the same displacement vector:
$$Q_2 - P = \begin{bmatrix} 4 - 2 \\ 1 - 3 \\ 1 - 1 \end{bmatrix} = \begin{bmatrix} 2 \\ -2 \\ 0 \end{bmatrix}$$
Now we find the dot product
$$(Q_2 - P) \cdot n = (2)(1) + (-2)(-2) + (0)(3) = 2 + 4 + 0 = \mathbf{6}$$
Waittt, halt. The result is not 0, that means that the point is above the plane, not in it.

Let's do another test: Testing $Q_3 = (0, 4, -1)$

We find the displacement:
$$Q_3 - P = \begin{bmatrix} 0 - 2 \\ 4 - 3 \\ -1 - 1 \end{bmatrix} = \begin{bmatrix} -2 \\ 1 \\ -2 \end{bmatrix}$$

Now we find the dot product:
$$(Q_3 - P) \cdot n = (-2)(1) + (1)(-2) + (-2)(3) = -2 - 2 - 6 = \mathbf{-10}$$

That means that the dot is below the plane. 

But we have a question... by how much are they above or bellow the plane?
To answer this question we will use this formula:
$$\text{Distance} = \frac{(Q - P) \cdot n}{\Vert{}n\Vert{}}$$

Since $n$ = $(1, -2, 3)$, we will find its magnitude: 
$$\Vert{}n\Vert{} = \sqrt{1^2 + (-2)^2 + 3^2} = \sqrt{14} \approx 3.74$$

So now our table would look like:

| **Point**          | **(Q−P)⋅n** | **Position relative to plane** | **Exact Perpendicular Distance**                                          |
| ------------------ | ----------- | ------------------------------ | ------------------------------------------------------------------------- |
| $Q_1 = (5, 6, 2)$  | $0$         | ON the plane                   | $\frac{0}{\sqrt{14}} = \mathbf{0 \text{ units}}$                          |
| $Q_2 = (4, 1, 1)$  | $+6$        | ABOVE the plane                | $\frac{6}{\sqrt{14}} \approx \mathbf{1.60 \text{ units}}$                 |
| $Q_3 = (0, 4, -1)$ | $-10$       | BELOW the plane                | $\frac{\Vert{}-10\Vert{}}{\sqrt{14}} \approx \mathbf{2.67 \text{ units}}$ |

struct PointNormalPlane
    p::Vector{Float64}
    n::Vector{Float64}
end

function evaluate_point(plane::PointNormalPlane, r::Vector{Float64})

    displace = r - plane.p

    dot_result = dot(displace, plane.n)

    signed_dot = dot_result/norm(plane.n)

    if abs(signed_dot) < 1e-9
        status = :on_plane
    elseif signed_dot > 0
        status = :above_plane
    else
        status = :below_plane
    end
    
    return status, signed_dot
end

println("Test 2: Status = ", status2, " | Distance = ", dist2)

## 2. General quadratic equation

Wait, didn't we just learn about the general quadratic equation?
Yes we learned one of its forms:
$$A x^2 + B xy + C y^2 + D x + E y + F = 0$$

But this form works only in 2D. While the new version is compatible for 3D+, that why we will use only the new form:
$$\mathbf{x}^T M \mathbf{x} + \mathbf{b}^T \mathbf{x} + c = 0$$
Now let's break it to pieces.
To do't confuse nobody, we will give an example, let us say that:
$$M = \begin{bmatrix} m_{11} & m_{12} \\\\ m_{21} & m_{22} \end{bmatrix}, \quad \mathbf{b} = \begin{bmatrix} b_1 \\\\ b_2 \end{bmatrix}, \quad c$$
Yeah, let's compute it by using the formula.
We will break the formula to pieces:

1. First step, the pure quadratic part ($\mathbf{x}^T M \mathbf{x}$) (We will add what we have):
$$\begin{bmatrix} x & y \end{bmatrix} \begin{bmatrix} m_{11} & m_{12} \\\\ m_{21} & m_{22} \end{bmatrix} \begin{bmatrix} x \\\\ y \end{bmatrix}$$
Now let us solve it!
Since there is just multiplication, we choose from where to start. 
We will firstly multiply the matrix by the column vector firstly:
$$= \begin{bmatrix} x & y \end{bmatrix} \begin{bmatrix} m_{11}x + m_{12}y \\\\ m_{21}x + m_{22}y \end{bmatrix}$$

Now we will take the dot product with the row vector:
$$= x(m_{11}x + m_{12}y) + y(m_{21}x + m_{22}y)$$

$$= m_{11}x^2 + m_{12}xy + m_{21}xy + m_{22}y^2$$

$$= m_{11}x^2 + (m_{12} + m_{21})xy + m_{22}y^2$$
that part was basic algebra.

Now we will do the second step
2. Second step, The Linear Part ($\mathbf{b}^T \mathbf{x}$):
$$\begin{bmatrix} b_1 & b_2 \end{bmatrix} \begin{bmatrix} x \\\\ y \end{bmatrix} = b_1 x + b_2 y$$
Now we will do the last step:

3. Combine everything:
   $$m_{11}x^2 + (m_{12} + m_{21})xy + m_{22}y^2 + b_1 x + b_2 y + c = 0$$

We can recognize something, can't we?
$$\begin{array}{rccccccc} \text{Matrix Expansion:} & m_{11}x^2 & + & (m_{12} + m_{21})xy & + & m_{22}y^2 & + & b_1 x & + & b_2 y & + & c & = 0 \\\\ \text{Scalar Form:} & A x^2 & + & B xy & + & C y^2 & + & D x & + & E y & + & F & = 0 \end{array}$$

And I'll say a cute claim before starting something else.
Notice that $B = m_{12} + m_{21}$. In linear algebra, we almost always force $M$ to be a symmetric matrix ($m_{12} = m_{21}$).
If $B = 6$, we simply set $m_{12} = 3$ and $m_{21} = 3$:

Now let's use it on a 3D one, for fun:

- **Matrix $A$ ($3 \times 3$):** $A = \begin{bmatrix} 3 & 0 & 1 \\\\ 0 & 2 & 0 \\\\ 1 & 0 & 3 \end{bmatrix}$ 

- **Vector $\mathbf{b}$ ($3 \times 1$):** $\mathbf{b} = \begin{bmatrix} -2 \\\\ 4 \\\\ 0 \end{bmatrix}$

- **Scalar $c$:** $c = -8$

now we will start from the pure quadratic part:
$$A \mathbf{x} = \begin{bmatrix} 3 & 0 & 1 \\\\ 0 & 2 & 0 \\\\ 1 & 0 & 3 \end{bmatrix} \begin{bmatrix} x \\\\ y \\\\ z \end{bmatrix} = \begin{bmatrix} 3x + 0y + 1z \\\\ 0x + 2y + 0z \\\\ 1x + 0y + 3z \end{bmatrix} = \begin{bmatrix} 3x + z \\\\ 2y \\\\ x + 3z \end{bmatrix}$$

Now we get the dot product with the row vector:
$$\mathbf{x}^T (A \mathbf{x}) = \begin{bmatrix} x & y & z \end{bmatrix} \begin{bmatrix} 3x + z \\\\ 2y \\\\ x + 3z \end{bmatrix}$$

$$= x(3x + z) + y(2y) + z(x + 3z)$$

$$= 3x^2 + xz + 2y^2 + xz + 3z^2$$

$$= 3x^2 + 2y^2 + 3z^2 + 2xz$$
Now we will do the linear part:
$$\mathbf{b}^T \mathbf{x} = \begin{bmatrix} -2 & 4 & 0 \end{bmatrix} \begin{bmatrix} x \\\\ y \\\\ z \end{bmatrix} = -2x + 4y + 0z = -2x + 4y$$

Now we will just stick them togheter:
$$\underbrace{(3x^2 + 2y^2 + 3z^2 + 2xz)}_{\mathbf{x}^T A \mathbf{x}} + \underbrace{(-2x + 4y)}_{\mathbf{b}^T \mathbf{x}} + \underbrace{(-8)}_{c} = 0$$

$$\mathbf{3x^2 + 2y^2 + 3z^2 + 2xz - 2x + 4y - 8 = 0}$$

## 3. Classifying shape by eigenvalues

Why do we even need to recognize shape by eigenvalues? Because if I give you this:

$$10y^2_1​+3y^2_2​$$
The ugly $xy$ disappears.
This always happens. After rotating, every quadratic equation becomes:
$$\lambda_1y^2_1 + \lambda_2y^2_2$$

Imagine this three outcomes:
1. Ellipse
$$5y^2_1​+2y^2_2​ \quad or \quad -5y^2_1​-2y^2_2​$$

​
2. Hyperbola
$$5y^2_1 - 2y^2_2 \quad \text{or} \quad -5y^2_1 + 2y^2_2$$

now one of the coefficients is negative and the other is positive (-, +) or (+, -)
What shape it has? It is a hyperbola.

3. Parabola
$$5y^2_1​+0y^2_2 \ \quad \text{or} \quad 0y^2_1​+2y^2_2​$$

One of the coefficients is negative while the other may be whether positive or negative (-, 0) or (+, 0).
What shape it has? It is a parabola.

TLDR

| **Eigenvalue Signs**     | **Signature**              | **Determinant**             | **Geometric Shape** |
| ------------------------ | -------------------------- | --------------------------- | ------------------- |
| **$(+, +)$ or $(-,-)$**  | $(2, 0, 0)$ or $(0, 2, 0)$ | $\operatorname{det}(A) > 0$ | **Ellipse**         |
| **$(+, -)$ or $(-, +)$** | $(1, 1, 0)$                | $\operatorname{det}(A) < 0$ | **Hyperbola**       |
| **$(+, 0)$ or $(-, 0)$** | $(1, 0, 1)$ or $(0, 1, 1)$ | $\operatorname{det}(A) = 0$ | **Parabola**        |

That what we call the signatures.

#### 4. Arc-length integral

Let's say that we went hiking and the map looks like:
`Start ●~~~~~~~~~~~~~~~~~~~~● Finish`

The road curves...
And if somebody ask us "How long is the hike?"

Can we simply do: `Finish - Start`? No. We can't.

Because that measures only a straight-line distance (1D).

Now imagine you went hiking. On a mountain. The map looks like:
```
        Mountain

           ●
         /   \
Start ●         ● Finish
```

The straight line might be 100 meters, while the road 160 meters. Why? Because the road is not flat, it is bended.
That the entire purpose of the arc-length. 
It asks:

"What is the actual length of the curve? (Start -> All the curves -> Finish. This doesn't skip any curves, it acts like a car's odometer tracking every turn)"

Not

"How far apart are the endpoints (Start -> Finish. It skips every curve, it just looks everything in a straight line. Like a crow flying from Start to end) - $d = \sqrt{(\Delta x)^2 + (\Delta y)^2}$"

Another example would be:

The map shows:
`Home ------------------ Mall`
It writes that the distance is just 5 km.

While the road is:
```
Home
   \
    \
     \
      \____
           \
            \____
                 \
                  Mall
```

Making the length to be 8 km - the arc-length. 

But we will zoom in enormously, and under this zoom the curve looks like a line. So it will be written as: 
$$ds$$
which is literally just a tiny piece of distance.

If we move a tiny bit horizontally, we get:
$$dx$$
if we move a tiny bit vertically, we get:
$$dy$$
and so we get a tiny triangle:
```
       ●
       |
       | dy
       |
●------●
   dx
```

That is why we need to find that tiny piece of distance... with someones help... Pythagoras.

That why we can write it for now as:
$$ds = \sqrt{dx^2 + dy^2}$$
But that the formula just for a tiny piece.
We need the whole curve.
But how do we select the curve from this to that?

We will use integrals.
So the total length is:
$$L = \int ds$$
But, we make it even parametric, so we can move along.
$$x = x(t)$$
$$y = y(t)$$

That why we make a small change:
$$dx = \frac{dx}{dt} \, dt$$
$$dy = \frac{dy}{dt} \, dt$$
That why now we stick all togheter:
$$L = \int_{a}^{b} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} \, dt$$
And now we have the whole Arc-length formula that we needed.

Now let's see what our GPS tells us in the case we already solved:
$$x=2\cos t \quad, \quad y=2\sin t \quad , \quad z = t$$
Let's calculate the distance between our start and finish.
 $0≤t≤2π$ 

Our start: $t = 0$ → position is $(2, 0, 0)$
Our finish: $t = 2\pi$ → position is $(2, 0, 2\pi)$

Now we will measure the distance using the basic formula:
$$d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2 + (z_2 - z_1)^2}$$
$$d = \sqrt{(2 - 2)^2 + (0 - 0)^2 + (2\pi - 0)^2} =$$
$$=\sqrt{4\pi^2} = 2\pi \approx 6.28$$

This is the straight line that this distance actually calculates. Since our figure looks like: 
![[Code_Generated_Image (3).png|565]]

We understand that this distance just made a vertical line that reaches $t = 2\pi$ without a care in the world.

But now we will use the arc-length, and get the real distance. 
$$L = \int_{a}^{b} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} \, dt$$

I will not skip the math steps, since knowing them is not bad at all.
Firstly we will find all of the derivatives with respect to t (Partial derivatives):
$$\frac{dx}{dt} = \frac{d}{dt}(2\cos t) = -2\sin t$$
$$\frac{dy}{dt} = \frac{d}{dt}(2\sin t) = 2\cos t$$
$$\frac{dz}{dt} = \frac{d}{dt}(t) = 1$$
Now we square all of them:
$$\left(\frac{dx}{dt}\right)^2 = (-2\sin t)^2 = 4\sin^2 t$$
$$\left(\frac{dy}{dt}\right)^2 = (2\cos t)^2 = 4\cos^2 t$$
$$\left(\frac{dz}{dt}\right)^2 = 1^2 = 1$$
Now we have:
$$L = \int_0^{2\pi}\sqrt{4\sin^2t + 4\cos^2t + 1} = \sqrt{4(\sin^2t + \cos^2t) + 1} $$

Using basic trigonometry, we understand that 
$$cos^2 + sin^2 = 1$$
so now we have:
$$L = \int_0^{2\pi} \sqrt{4(1) + 1} =$$$$ = \int_0^{2\pi} \sqrt5$$
Since $\sqrt{5}$ is a constant, we can factor it out of the integral
$$L = \sqrt{5} \int_{0}^{2\pi} 1 \, dt$$
and now we evaluate the antiderivative:
$$L = \sqrt{5} \Big[ t \Big]_{0}^{2\pi}$$
$$L = \sqrt{5}(2\pi - 0) = 2\pi\sqrt{5}$$

So that the result. Firstly we predicted that going all the way from $0$ to $2\pi$:

- Distance:  $2\pi \approx 6.28$
- Reality (Arc-length): $2\pi\sqrt{5} \approx 14.04$ 

So we can clearly see that the reality is harsher and more accurate.

# 3. Chapter 3: Metrics and transformations

## 1. positivity, symmetry, triangle inequality

Before we call everything a distance... there are some properties that a distance must satisfy.
Here is where a metric comes from.

I know that we learnt what a metric is, yet let us recap it a bit.

A metric is simply a mathematical definition of distance. So instead of satisfying:
"distance is: $\sqrt{x^2 + y^2}$"

We will ask:
"Which rules must this distance obey"

Before making a ruler, we ask ourselves some questions
- What should a ruler always do?
- What would make a ruler "broken"?

Those rules are the metric axioms:

Now we will explain the idea of a bad ruler:
1. "The distance from A to A is 7 meters" - what? Of course it can't be 7.
   Because if we don't move, the distance must always be 0. There is no way it is 7.
   This is our first axiom.

2. ```
   Home → School = 8 km

   School → Home = 20 km
   ```

   That is not how life work. It doesn't matter how we measure. If the distance from point A to point B is 2 km, the distance from point B to point A must be 2 km too.
   That is our second axiom

3. ```
   Home → Bakery = 2 km

   Bakery → School = 3 km

   Home → School = 20 km
   ```

   That has no sense. Because walking through the bakery cannot magically be shorter than the shortest route. 
   That becomes another axiom.

From here we understand that a good distance must satisfy some rules.
And we have 4 principal rules.

### 1. First of the Four Metric Axioms: Positivity

The first universal rule tells us:

**"The distance must never be negative"**

In math it will look like:
$$d(A, B) ≥ 0$$
The first part - $d(A, B)$ translates as:
"the distance between points A and B"

for example:

```
Home → School = 5 km
Home → School = -5 km?
```

Negative distance makes no sense in ordinary geometry.

Even 0 is allowed and the second metric axiom will explain how.

### 2. Second of the Four Metric Axioms: Dentity of Indiscernibles

This long name translates in a really easy way:

**"The only thing that is zero units away from you is you."**

$${d(A, B) = 0 \iff A = B.}$$
What does it means? 

It means that there is no way that we move from point A to point B and the distance is equal to 0.
It tells us that the only way to get a distance of 0 is not moving in the first place.

For example:

```
Chair → Chair = 0 meters - True
Chair → Table = 0 meters - False
```

Because zero happens only when the two points are the same.

Now we go with the next rule.

### 3. Third of the Four Metric Axioms: Symmetry 

In geometry symmetry means:

**"Distance doesn't care which direction you measure"**

This simply means:
```
Home → School = 8 km
School → Home = 8 km
```

This is forced to happen. Because there is no way that the way from school to home will result in 40 km. The heck we did, passed the Everest two times?

This rule is really easy. We already grasped the concept.

### 4. Last of the Four Metric Axioms: Triangle Inequality

The idea behind it is really easy.

Imagine you went from home to the nearest bakery and then to school.
```
Home ----- Bakery ----- School
```

Let's say that:
```
Home → Bakery = 2 km
Bakery → School = 5 km
```

Now if we add them
```
Home -> School = 7 km
```

The distance can not be more then 7. Because the direct distance is always smaller than the indirect one (Going from home to the bakery and only then to the school.)

The formula that tells the same stuff but mathematically is:
$$\boxed{d(A, C) \le d(A, B) + d(B, C).}$$
The direct distance is always less than or equal to going through another point.

It takes the idea of the triangle. One side of a triangle is never longer than the other two sides added together.


But why do we care about this rules?
Because if the distance we invented is something as:
$$d(A, B) = -5$$
Is impossible, because it fails the positivity test.

But there are exceptions. For example, it always depend by space, because in the Minkowski space we have a negative distance:
$$s^2 =-c^2t^2 + x^2 + y^2 + z^2$$
 Sometimes, $s^2$ breaks the first axiom of a metric - Positivity.
 That is an interesting idea that shows how badly spaces change from each other.

Another transformation is the mirror:

```
      ●●● 
    ●     ●

Did the parabola got bigger? Nope.

The only thing that reflection did was to flip the points.

So now we have three transformation:

| Transformation | Distance preserved? |
| -------------- | ------------------- |
| Translation    | Yes                 |
| Rotation       | Yes                 |
| Reflection     | Yes                 |
This are called Isometries.

From greek it translates as:
- Iso = equal
- Metric = distance

This means that an isometry never changes distances.

If the transformation is not isometric, it will change the shape of the points. 
They will get stretched, shrunk and so on.

Let's give an example:
$$A = (0, 0)$$
$$B = (3, 4)$$

Now we find the distance: 
$$d = \sqrt{(3 - 0)^2 + (4 - 0)^2} = \sqrt{9 + 16} = 5$$
Now let's just rotate it to $90^o$.
$$R = \begin{bmatrix} 0 & -1 \\\\ 1 & 0 \end{bmatrix}$$

Don't get too surprised where this came from. We will just use it.

Firstly we will rotate A:
$$R \begin{bmatrix} 0 \\\\ 0 \end{bmatrix} = \begin{bmatrix} 0 \\\\ 0 \end{bmatrix}.$$
No surprise her.

Now we will rotate B:
$$R \begin{bmatrix} 3 \\\\ 4 \end{bmatrix} = \begin{bmatrix} -4 \\\\ 3 \end{bmatrix}.$$
The new points are
$$A = (0, 0)$$
$$B = (-4, 3)$$

Now let's calculate the distance again:
$$\sqrt{(-4)^2 + 3^2} = \sqrt{16 + 9} = 5.$$
Same stuff.

And now we do a non-uniform scaling (Stretch just one side (x or y, not both. Because if we stretched both, that would be uniform scaling.))
$$R = \begin{bmatrix} 2 & 0 \\\\ 0 & 1 \end{bmatrix}$$
We stretch just the x side
Now we get the new points:
$$B = (3, 4)$$
Now B becomes:
$$B = (6, 4)$$Now we find the distance of B
$$\sqrt{6^2 + 4^2} = \sqrt{36 + 16} \approx 7.21$$
So originally we had 5, and now we have 7.21

That not an isometry.
So in the end, the isomtery preserve both distances and angles.
But maybe we want to preserve the angle instead of the distance.

This will be a conformal transformation. This usually doesn't preserve the distance, but the angle.

This time we don't care about distance changes, we care just about the angle.

Let's draw on a balloon a road at $90^o$, then we will inflate the balloon. What happened? The balloon became bigger and the distance changed, but the road has what angle? It is still at an $90^o$ angle - it didn't change.

A little example would be that we have two points:

we get:

$$B = (2, 2)$$

so... did the angle changed? No. It did not.
