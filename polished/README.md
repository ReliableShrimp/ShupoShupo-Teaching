# The Learning Zone (`/polished`)

This is the clean room. If you are here, it means you want to study the concepts without having to wade through 3 AM syntax errors and broken matrix dimensions. Every module in this directory has been refactored, commented, and verified to run successfully.

## What's Inside
* **Clean Implementations:** Production-style code layouts with a clear separation of concerns.
* **Math Explanations:** Clean, fully rendered LaTeX and Unicode documentation explaining *why* the code works, not just *how*.
* **Step-by-Step Evolution:** Structured folders (starting with `month_1`) mapping out the exact progression from core mathematical primitives to advanced architectures.

## How to Study Here
1. Read the local markdown explanations first to understand the core math.
2. Run the scripts sequentially. They are designed to work out of the box.
3. If you get stuck on a concept, open the corresponding folder in `/unpolished` to see the messy, trial-and-error process of how the solution was originally found. 

*Found an actual bug or a mathematical flaw here? Open an Issue or submit a PR—let's keep the clean room clean.*
